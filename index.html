01 국어교육의 이해

국어교육은 학습자가 국어를 통해 의미를 구성하고 소통하며, 사고와 문화를 향유하도록 돕는 교육이다.

국어교육의 주요 목적① 의사소통 능력 신장
② 사고력 및 문제 해결력 함양
③ 문학·문화 향유 능력 신장
④ 공동체의 언어문화 발전에 참여
국어과의 교과적 성격언어를 도구로 삼는 교과이면서, 언어 자체를 탐구하는 교과이다. 실제 언어생활과 학습자의 삶을 연결한다.
국어 능력문법 지식만이 아니라 상황과 맥락에 맞게 듣고·말하고·읽고·쓰며 의미를 구성하는 통합적 능력이다.
언어 사용의 맥락목적, 상황, 참여자, 매체, 사회·문화적 관습 등이 언어 사용과 의미 해석에 영향을 준다.
핵심: 국어교육은 지식 전달에 머무르지 않고 실제 언어생활에서 지식과 기능을 활용하는 능력을 기르는 데 초점을 둔다.

02 국어과 교육과정

교육과정의 구성 요소

요소핵심 질문
성격국어과는 어떤 교과인가?
목표무엇을 기르고자 하는가?
내용 체계무엇을 가르치고 배울 것인가?
성취기준학습 후 무엇을 할 수 있어야 하는가?
교수·학습 및 평가어떻게 가르치고 성취를 확인할 것인가?

국어과의 주요 영역

듣기·말하기음성 언어를 중심으로 의미를 협력적으로 구성하고 소통한다.
읽기글과 독자의 상호작용을 통해 의미를 구성하고 비판적으로 이해한다.
쓰기목적·독자·상황을 고려해 의미를 생성하고 조직하여 표현한다.
문법국어의 구조와 규칙, 사용 양상을 탐구하고 언어생활에 적용한다.
문학작품을 수용·생산하며 상상력과 심미적 감수성, 문학 문화를 기른다.
매체매체 자료를 비판적으로 이해하고 목적에 맞게 생산·소통한다.

※ 교육과정의 영역 명칭과 세부 구성은 적용하는 교육과정 및 학교급에 따라 확인해야 한다.

내용을 바라보는 관점

개념·원리 등의 지식, 실제 언어활동을 수행하는 과정·기능, 태도·가치가 서로 연결된다. 지식은 실제 수행에 활용될 때 교육적 의미가 커진다.

03 언어와 국어 지식

언어의 층위

층위탐구 대상예시
음운말소리의 체계와 변동음운 체계, 음운 변동
형태형태소와 단어의 짜임형태소 분석, 단어 형성
통사문장 구성과 문법 관계문장 성분, 문장 짜임
의미단어·문장 등의 의미다의어, 동의 관계, 문장 의미
담화·화용맥락 속 발화와 텍스트발화 의도, 지시 표현, 담화 구조

문법 교육의 방향

  • 규칙을 암기하는 데 그치지 않고 실제 언어 자료를 관찰·분석한다.
  • 언어 현상에 대한 가설을 세우고 자료를 근거로 검증한다.
  • 문법 지식을 말하기·읽기·쓰기 등 실제 언어생활에 적용한다.
  • 언어의 규칙성과 함께 다양성, 변화 가능성, 사회적 맥락을 고려한다.
문법 탐구의 흐름: 자료 관찰 → 문제 발견 → 가설 설정 → 자료 분석·검증 → 규칙 정리 → 실제 언어생활에 적용

04 화법·작문

화법의 핵심상호작용, 협력적 의미 구성, 상황·참여자·목적 고려, 경청과 조정
말하기의 주요 기능정보 전달, 설득, 친교·정서 표현, 문제 해결 및 관계 형성
작문의 핵심필자·독자·목적·맥락을 고려한 의미 구성과 사회적 소통
쓰기 과정계획하기 → 내용 생성하기 → 내용 조직하기 → 표현하기 → 고쳐쓰기

과정 중심 쓰기

쓰기를 한 번에 완성하는 결과가 아니라 여러 단계가 순환·반복되는 과정으로 본다. 초고 작성 후에도 독자와 목적을 점검하며 내용을 보완한다.

고쳐쓰기의 초점

  • 내용: 주제에 적합한가, 근거가 충분한가?
  • 조직: 글의 구조와 문단 간 연결이 자연스러운가?
  • 표현: 독자와 상황에 적합하고 명확한가?
  • 표기: 맞춤법과 문장 부호가 적절한가?

05 독서

읽기의 의미 구성 관점

관점핵심 설명교육적 시사점
상향식문자·단어·문장 등 작은 단위에서 큰 의미 단위로 처리해독과 어휘, 문장 이해 지원
하향식독자의 배경지식과 예측을 활용해 의미 구성배경지식 활성화와 목적 설정
상호작용텍스트 정보와 독자의 지식·전략이 상호작용텍스트 근거와 독자 추론을 함께 활용

읽기 과정의 전략

읽기 전목적 설정, 배경지식 활성화, 내용 예측
읽는 중질문 생성, 중심 내용 파악, 추론, 점검·조정
읽은 후요약, 평가, 적용, 다른 자료와 연결
초인지자신의 이해 상태를 점검하고 전략을 선택·수정하는 능력
독서 지도 포인트: 정답 찾기만 강조하기보다 독자가 텍스트 근거를 바탕으로 의미를 구성하고 자신의 해석을 점검하도록 돕는다.

06 문학

문학 교육의 목표

  • 작품의 내용과 형식을 이해하고 해석하는 능력
  • 작품에 대한 감수성과 상상력, 심미적 경험
  • 다양한 삶과 가치에 대한 이해 및 성찰
  • 문학 작품을 능동적으로 수용하고 창의적으로 생산하는 능력

문학 감상의 주요 관점

작품 중심작품 내부의 구성, 표현, 형식과 의미 관계에 주목한다.
독자 중심독자의 경험과 반응, 의미 구성 과정을 중시한다.
맥락 중심작가·사회·역사·문화적 맥락을 고려해 작품을 이해한다.
상호작용 관점작품, 독자, 맥락이 상호작용하며 의미가 구성된다고 본다.

문학 수업의 유의점

교사의 단일 해석을 전달하기보다 학습자의 다양한 반응을 존중하되, 작품의 구체적 표현과 맥락을 근거로 해석을 정교화하도록 지도한다.

07 교수·학습

교수·학습의 기본 원리

  • 학습자 중심: 학습자의 수준, 흥미, 경험과 언어생활을 고려한다.
  • 실제성: 실제 언어 사용과 유사한 과제 및 맥락을 제공한다.
  • 상호작용: 교사·학습자·학습자 간 대화와 협력을 활용한다.
  • 통합성: 듣기·말하기·읽기·쓰기·문법·문학 활동을 유기적으로 연결한다.
  • 과정 중시: 결과뿐 아니라 수행 과정과 전략 사용을 살핀다.

대표 교수·학습 접근

접근특징
직접 교수교사의 명시적 설명과 시범, 안내된 연습, 독립 수행을 단계적으로 제공
협동 학습공동 목표 아래 구성원이 상호 의존하며 개인 책무성을 갖고 학습
탐구 학습문제·자료를 바탕으로 질문하고 근거를 찾아 원리나 결론을 도출
문제 중심 학습실제적이고 비구조화된 문제를 해결하는 과정에서 지식과 기능을 학습
토의·토론 학습근거 제시와 경청, 관점 조정으로 공동의 이해 또는 합리적 판단에 도달

08 평가

유형시기·목적활용
진단 평가수업 전, 출발점 행동과 선수 학습 확인수업 계획과 수준별 지원
형성 평가수업 중, 학습 과정과 이해 정도 확인즉각적 피드백과 교수·학습 개선
총괄 평가단원·학기 등 일정 기간 후 성취 확인종합적 성취 판단

평가 방법

선택형·서답형지식과 이해, 적용 능력을 문항으로 확인
수행 평가실제적인 과제 수행 과정과 결과를 평가
관찰·면담언어활동 과정과 전략, 상호작용을 살핌
포트폴리오시간에 따른 산출물과 성장 과정을 종합적으로 확인

좋은 평가의 조건

타당도 측정하려는 것을 제대로 측정하는가? 신뢰도 결과가 일관적인가? 공정성 학습자에게 부당한 불이익이 없는가? 실용성 시행과 해석이 현실적인가?

피드백: 점수나 정오 판단에 그치지 않고 무엇을 잘했고 다음에 무엇을 어떻게 개선할지 구체적으로 알려준다.

09 주요 수업 모형 빠른 정리

직접 교수 모형

설명하기 → 시범 보이기 → 질문하기 → 활동하기. 교사가 전략이나 기능을 명시적으로 안내하고 점차 학습자의 독립 수행을 돕는다.

문제 해결 학습

문제 확인 → 해결 방법 탐색 → 해결 실행 → 일반화·정리. 문제를 분석하고 적절한 전략을 선택·적용한다.

반응 중심 문학 수업

반응의 형성 → 반응의 명료화 → 반응의 심화 → 반응의 일반화. 학습자의 문학적 반응을 출발점으로 삼아 작품 근거와 다른 관점으로 해석을 깊게 한다.

과정 중심 쓰기

계획·내용 생성·조직·표현·고쳐쓰기 단계가 순환한다. 교사는 단계별 전략 지도와 피드백을 제공한다.

탐구 학습

문제 제기 → 가설 설정 → 자료 수집·분석 → 가설 검증 → 결론 도출. 자료에 근거해 규칙이나 원리를 발견한다.

수업 모형의 단계 명칭과 세부 절차는 교재·학자·적용 맥락에 따라 다르게 제시될 수 있다.
